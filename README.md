AllegroManager

Wersja: 1.0.0 (projekt testowy)

Opis aplikacji

AllegroManager to prywatna aplikacja komputerowa dla systemu Windows, przeznaczona do przygotowywania ofert sprzedaży w serwisie Allegro.

Planowane funkcje

Przygotowywanie i edycja szkiców ofert.

Import zdjęć produktów.

Odczytywanie ustawień sprzedaży i cenników dostawy.

Pobieranie kategorii i parametrów produktów.

Obsługa zgodności części samochodowych z pojazdami.

Archiwizowanie ofert na komputerze użytkownika.

Integracja z Allegro

Aplikacja jest rozwijana z wykorzystaniem oficjalnego Allegro REST API.

Logowanie użytkownika będzie obsługiwane za pomocą protokołu OAuth 2.0.

Status projektu

Projekt znajduje się w fazie rozwoju i testów w środowisku Allegro Sandbox.

Kontakt

Kontakt z administratorem projektu jest możliwy przez zakładkę Issues w tym repozytorium.
